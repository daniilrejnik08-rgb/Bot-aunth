# Discord Verify Bot

Красивый бот верификации на Python + SQLite.

## Что умеет
- Красивая кнопка верификации
- Приветствие в канал + в личные сообщения
- Автоматическая выдача/снятие ролей
- Логи с аватарами и датой создания аккаунта
- Таймер на верификацию (кик при просрочке)
- Настройка через slash-команды
- База данных SQLite

## Установка

1. Установи зависимости:
```bash
pip install -r requirements.txt
```

2. Открой `config.py` и вставь токен:
```python
TOKEN = "твой_токен_сюда"
```

3. В Discord Developer Portal включи:
   - **Server Members Intent**
   - **Message Content Intent** (по желанию)

4. Запусти:
```bash
python main.py
```

## Настройка

1. Создай роли:
   - `Неверифицирован` (все каналы скрыты кроме верификации)
   - `Участник`

2. Создай каналы:
   - `#верификация`
   - `#приветствие`
   - `#логи`

3. Выполни `/setup` и укажи роли + каналы

4. Отправь кнопку командой `/send_verify`

## Команды
| Команда        | Описание                          |
|----------------|-----------------------------------|
| `/setup`       | Настроить роли и каналы           |
| `/send_verify` | Отправить сообщение с кнопкой     |
| `/settings`    | Посмотреть текущие настройки      |
