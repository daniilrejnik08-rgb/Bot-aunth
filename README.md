# Discord Verify + Moderation Bot

Бот верификации + модерации на Python + SQLite.

## Возможности

### Верификация
- Кнопка верификации
- Приветствие в канал + в ЛС
- Таймер + автокик
- Логи верификации

### Модерация
- **Мут / Размут** (через роль) — без таймаута Discord
- **Мут в одном канале** (через права канала)
- **Жалобы** (`/report`) — модальное окно + лог
- **Автомод плохих слов** — удаление + опционально мут
- **Антиспам** — мут при быстрых сообщениях
- **Антирассылка** — блокировка массовых упоминаний и @everyone
- **Логи всего** в отдельный канал модерации

## Установка

```bash
pip install -r requirements.txt
```

В `config.py` вставь токен бота.

В Developer Portal включи:
- SERVER MEMBERS INTENT
- MESSAGE CONTENT INTENT

Запуск:
```bash
python main.py
```

## Первая настройка

1. Создай роли:
   - `Неверифицирован`
   - `Участник`
   - `Muted` (запрети ей писать сообщения во всех каналах)

2. Создай каналы:
   - `#верификация`
   - `#приветствие`
   - `#логи`
   - `#мод-логи`

3. Выполни:
```
/setup
```
и укажи все роли и каналы (особенно `muted_role` и `mod_log_channel`).

4. Отправь кнопку:
```
/send_verify
```

## Команды модерации

| Команда | Описание |
|---------|----------|
| `/mute @user [причина] [канал]` | Мут (роль или только в канале) |
| `/unmute @user [канал]` | Размут |
| `/report @user` | Пожаловаться |
| `/addword слово` | Добавить запрещённое слово |
| `/removeword слово` | Удалить слово |
| `/wordlist` | Список запрещённых слов |
| `/settings` | Текущие настройки |

## Настройки антиспама и антирассылки

В `config.py` можно менять:
- `SPAM_MESSAGES` / `SPAM_SECONDS` — порог спама
- `SPAM_MUTE_MINUTES` — длительность мута за спам
- `MAX_MENTIONS` — сколько упоминаний считается рассылкой
- `BAD_WORDS_ACTION` — `delete` / `mute` / `both`
